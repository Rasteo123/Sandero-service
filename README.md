# Sandero-service

Скилл Claude Code с RAG-поиском по документации **Renault Sandero II /
Sandero Stepway II** (платформа X52 Ph2, 2014+; электрика общая с Logan II).
Отвечает на вопросы по эксплуатации, обслуживанию и электрике **со ссылкой
на конкретную страницу руководства**.

```
$ python3 .claude/skills/sandero-service/scripts/search.py "какое реле топливного насоса" --top 1

Запрос: какое реле топливного насоса   найдено фрагментов: 1

[1] Renault Sandero II / Logan II — электросхемы, монтажные блоки (иллюстрации) —
    РЕЛЕ МОНТАЖНОГО БЛОКА В МОТОРНОМ ОТСЕКЕ — таблица назначения — иллюстрация 3.jpg
    id=wiring:3.jpg:0  score=39.16
    https://drive.google.com/file/d/1QfdqFrxe_zjZ26nPFGmxSKd_cUrgoYIJ/view
   K1 — реле вентилятора отопителя; запитывает электродвигатель вентилятора
   отопителя. … K5 — реле топливного насоса и катушки зажигания; топливный насос
   и катушка зажигания. K6 — главное реле системы управления двигателем; …
```

## Источники

Всё собрано из файлов на Google Диске владельца:

| Документ | Объём | В индексе |
|---|---|---|
| `Сандеро.pdf` — руководство по эксплуатации, RUS (NU1232-8) | 300 стр. | ✓ 542 фрагмента |
| `Sandero_2_-_993-8_ENG_копия.pdf` — driver's handbook, ENG | 262 стр. | ✓ 431 фрагмент |
| 22 иллюстрации `1.jpg`-`22.jpg` — электросхемы, монтажные блоки | — | ✓ 28 фрагментов |
| `2012-2016_RENAULT_Sandero_SM.pdf` — сервисный мануал | 83 МБ | ✗ скан без текстового слоя |
| `Renault LOGAN II.pdf` — руководство по ремонту | 87 МБ | ✗ скан без текстового слоя |

Два последних не вошли по двум причинам сразу: коннектор Google Drive не
отдаёт файлы больше 10 МБ, а текстового слоя в них нет — нужен OCR.
Поэтому в корпусе есть эксплуатация, обслуживание и электрика, но нет
моментов затяжки, процедур разборки и каталожных номеров.

## Как это работает

Поиск не требует ни сети, ни зависимостей, ни ключей API — это BM25 поверх
подготовленного корпуса, собираемый в памяти за доли секунды.

- **Чанкинг по страницам.** `ingest.py` чистит текстовый слой PDF от
  типографского мусора и выносок к иллюстрациям, склеивает переносы, ловит
  заголовок раздела и номер страницы бумажного руководства — чтобы каждый
  фрагмент можно было процитировать точно.
- **Морфология.** Стеммер Портера для русского и облегчённый для
  английского: «масла», «маслом», «масло» дают одну основу.
- **Расширение запроса.** Словарь доменных синонимов (`то` → «техническое
  обслуживание», «печка» → «отопитель», «предохранитель» → `fuse`) в том
  числе связывает русские и английские термины, поэтому русский вопрос
  находит ответ в англоязычном руководстве.
- **Опечатки.** Незнакомое слово запроса подтягивается к словарю индекса по
  символьным триграммам: «давлени в шынах» находит «давление в шинах».
- **Ранжирование.** К BM25 добавлены надбавка за фразу (слова запроса
  стоят рядом) и за совпадение языка запроса с языком документа.
- **Иллюстрации.** Растровые схемы не ищутся сами по себе, поэтому их
  легенды и таблицы предохранителей перенесены в корпус текстом, а фрагмент
  ссылается на файл и на Google Диск.

## Использование

```bash
S=.claude/skills/sandero-service/scripts/search.py

python3 $S "как проверить уровень масла"
python3 $S "давление в шинах" --lang ru --chapter 4
python3 $S "какой предохранитель на прикуриватель" --doc wiring
python3 $S "tyre pressure" --doc en_owner --full
python3 $S "предохранители" --top 8 --per-doc 2
python3 $S --list-sources
```

В сессии Claude Code скилл вызывается сам, когда речь заходит о Sandero;
явно — `/sandero-service`.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

28 тестов: морфология и токенизация, разбор страниц PDF, ранжирование и
фильтры BM25, целостность корпуса и эвал — 18 реальных вопросов, для каждого
проверяется, что нужный раздел руководства попал в топ-5. Эвал — гейт
качества: после изменений в чанкинге или ранжировании он должен оставаться
зелёным.

## Пересборка корпуса

```bash
pip install -r requirements.txt
python3 .claude/skills/sandero-service/scripts/ingest.py --stats
```

`corpus/` в git не хранится (бинарники и авторские права). Восстановить
исходники можно в сессии Claude Code с подключённым коннектором Google Drive:

1. Попросить Claude скачать файлы по `drive_file_id` из `data/sources.json`
   инструментом `download_file_content` — большие ответы коннектор
   складывает на диск в каталог `tool-results`.
2. Разложить их по местам:

   ```bash
   python3 .claude/skills/sandero-service/scripts/drive_import.py <каталог tool-results>
   ```

## Дополнить корпус

Чтобы добавить сервисный мануал и руководство по ремонту Logan II:

1. Скачать оба PDF с Google Диска вручную (веб-интерфейс не ограничен 10 МБ)
   и положить в `corpus/pdf/`.
2. Прогнать OCR — текстового слоя в сканах нет:

   ```bash
   ocrmypdf -l rus+eng --force-ocr corpus/pdf/Renault_LOGAN_II.pdf corpus/pdf/logan2_ocr.pdf
   ```

3. Добавить запись в `data/sources.json` с `"indexed": true` и путём к файлу.
4. `python3 .claude/skills/sandero-service/scripts/ingest.py --stats`
5. Дописать в `tests/eval_queries.jsonl` пару запросов по новым темам
   (моменты затяжки, процедуры разборки) и прогнать тесты.

## Оговорка

Корпус — руководства по эксплуатации, а не ремонтная документация. Скилл
отвечает только тем, что нашёл, и обязан говорить, когда ответа в корпусе
нет. Работы, связанные с тормозами, подушками безопасности и топливной
системой, руководство прямо адресует сервисной станции — эти предупреждения
скилл переносит в ответ.
